What it does

Run a permission-gated coding agent across local models, subscription CLIs, APIs, gateways, and cloud endpoints, with failover, acceptance checks, resumable sessions, MCP access, and a hash-chained trajectory.

Current use cases

  • model-neutral coding workflows
  • provider failover
  • reviewable tool execution

Inputs and outputs

Inputs

  • coding tasks and acceptance checks
  • repository context
  • endpoint profiles
  • tool grants

Outputs

  • proposed and applied code changes
  • acceptance-check results
  • resumable session state
  • hash-chained trajectories

Limitations and boundary

  • The command denylist is not a security boundary.

Boundary. Tool use remains permission-checked and limited to authorized repositories, systems, and endpoints.
