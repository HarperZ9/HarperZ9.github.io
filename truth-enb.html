Skyrim SE/AE · ENBSeries 0.504

What it does

Truth replaces Skyrim's visual finishing path with a Truth-authored ENBSeries suite. It renders the sky, fog, volumetric clouds, aurora, bloom, lens response, exposure, tone mapping, sun sprite, depth of field, and underwater stages as one deliberate look.

  • Five quality tiers from performance to cinematic
  • Original world-space atmosphere, cloud, and aurora shaders
  • Automatic exposure and filmic tone mapping with CPU reference implementations
  • A native camera bridge for inverse-view-projection and celestial data
  • Strict shader compilation, D3D11 WARP execution, and deterministic package tests

Who it is for

Players and authors

  • Skyrim SE/AE players using ENBSeries 0.504
  • ENB preset authors and Skyrim mod developers
  • Shader and graphics programmers

Where it runs

  • Skyrim SE/AE through an ENBSeries 0.504 host
  • Mod Organizer 2 with a Root Builder layout
  • Local C++23 and Direct3D 11 shader development

Rendering path

Inputs

  • Scene, bloom, lens, adaptation, depth, weather, and interior data
  • Camera and celestial parameters from the native bridge
  • One host overlay and one quality tier

Result

  • Atmosphere, fog, cloud, and aurora composition
  • Exposure and tone-mapped final image
  • Deterministic WARP reference captures and release-candidate archive

Required build dependency

ENB Runtime Core supplies the loaded-host resolver, runtime protocol, and bridge infrastructure used by the native camera path.

Optional integration

SkyrimBridge is optional for the base optical suite. Its celestial vector is required by the current procedural sky and sun path.

Release state and dependencies

  • v1.0.0-rc.1 remains a release candidate until the recorded live Skyrim SE/AE and ENBSeries 0.504 acceptance rows pass.
  • Truth does not redistribute ENBSeries, Address Library, Community Shaders, Effects 11, or Bethesda shader source.
  • The Effects 11 compatibility path currently lacks a compatible camera publisher, so world-space prepass composition stays disabled on that host.

Truth-authored code, configuration, plugin, and documentation are MIT licensed. External game, runtime, and dependency rights remain with their owners.
