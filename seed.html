Seed · private · C++23 · proprietary · nested in Array

Offensive security needs a lab, not a weapon.

Red-team assessments require code that exercises real techniques against controlled targets. Seed provides the runtime for that work: native C++23, compiled for the platform under test, with every module mapped to a specific ATT&CK technique and every fixture generated from synthetic data.

The lab runs offline. It produces assessment reports, not operational capability. The distinction is load-bearing: assessment means the output is a finding, not a compromise.

What it covers.

Credential assessment Exercises credential-harvesting techniques against synthetic stores. SAM, LSASS, DPAPI, browser credential stores, all with generated test data.
Evasion and persistence Process injection, indirect syscalls, registry-based persistence, service manipulation. Each technique produces an assessment finding with ATT&CK ID.
Network and lateral movement Protocol-level assessment of SMB, WMI, DCOM, and pass-the-hash scenarios against synthetic network fixtures.
Detection engineering Each module logs the artifacts a defender should detect. The lab produces both the red-team finding and the blue-team detection opportunity.
