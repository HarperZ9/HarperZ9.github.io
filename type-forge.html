How we know.

The forge is a JavaScript port of the engine Flywheel mints Zain Mint with. For the same parameters it writes the same font bytes. Four reference faces (the default, Bold, a light extended face and the runic capitals) match the original engine byte for byte, and an over-heavy weight is refused with the same words. A rule can refuse a mint. A bowl too heavy to keep its counter open is refused by name, and nothing is drawn.

    The seed is recorded in the receipt. The outlines do not read it yet, in this port or in the original, so every seed draws the same letters today.
