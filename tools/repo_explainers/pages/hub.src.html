Explainers

Each explainer starts with what the tool does for you, then walks through its mechanism as an animation you scroll or step through. Every command, number and verdict on a page came from running the repository at the commit it names, and every step cites the file it describes. Each page ends with the commands to try it, what the tool does not do, and a few questions to check what stuck.

The source of each page lives in its repository under docs/explainer/, so it changes in the same pull request as the code it describes.

For narrated films on the ideas behind the work, with every number sourced, see the explainer films. The first, Claiming got cheap. Checking did not., also plays live in your browser, drawn by the raw-native engine.

How these pages are checked

  • Values come from running the code: for example flywheel gate from the PyPI package, raw_native_cli built from source, and articulate check and verify.
  • Where a page draws an illustration, such as raw-native's 2D slice of the scene, it says so beside the drawing, and the counts belong to the drawing.
  • Each page supports reduced motion, works with the keyboard through its step buttons, and fits a phone screen.
  • A page describes its repository at one commit. When the code moves on, the page is updated in the pull request that changes the behaviour it shows.
