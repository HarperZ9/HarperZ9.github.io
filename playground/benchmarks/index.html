Honest scope boundaries and measurement disclosures ([Reported])

  • Subprocess Launch Floor (~4.7 to 5.7 ms)Native and Zero-C PE32+ timings measure full Windows CreateProcess wall-clock process startup plus execution (~5 ms floor), whereas Node WASM and Python 3.12 measure in-process invocation. On sub-millisecond micro-kernels (NTC610 0.034 ms = 51.4x internal, PBR 16-Archetype 0.004 ms = 18.8x internal, JONSWAP 0.384 ms = 4.20x internal), full subprocess wall-clock time therefore appears slower than in-process Python; both raw subprocess p50 and internal context are kept visible.
  • Stateless WASM Wrapper & Software MathIn Indirect Draw Cull WASM (594.303 ms), each stateless metric export re-runs the 100K sweep (6 calls = 600K sweeps), and JONSWAP Ocean WASM (96.217 ms) executes software Taylor sin, cos, exp, and ln without native libm.
  • Target Subset CoverageZero-C PE32+ currently targets the integer and bitwise compiler subset (2/8 kernels: SHA-256 and ChaCha20-Poly1305), where it consistently beats C-runtime native binaries on cold-start latency. BuildLang WASM codegen covers 7/8 kernels and does not yet emit the log runtime import needed by K-Core Color.
