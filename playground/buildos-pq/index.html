Honest scope and cryptographic boundaries

Every .wasm payload on this page is verified against its pinned WebCrypto SHA-256 digest in pq_manifest.json before WebAssembly.instantiate runs. Both BuildOS slices (buildos_pq_hybrid_kem_zeroc.wasm and buildos_enclave_attest_zeroc.wasm) are compiled by the self-hosted Stage-2 BuildLang compiler with strictly 0 host imports; the two Titan modules (titan_test_time_mcts_oracle.wasm and titan_egraph_rlvr_synthesizer.wasm) import only 5 no-op env.print_* stubs with 0 filesystem, 0 network, and 0 syscall access. All cryptography is pre-audit research code published under the pure-OSI MIT license for deterministic verification and reproducibility; it has not undergone a third-party security audit.
