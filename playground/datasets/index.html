Honest scope and hygiene guarantees

Every row in BuildDB Parquet V6 (#68839) and JFC3P-14B-Oracle-v9 (#68861) is filtered fail-closed for pure-OSI MIT provenance (0 non-MIT rows, 0 local workstation paths, 0 secrets) with planted duplicate-ID, secret-leak, and failing-solution controls verified before sealing. All 200 shaders in the Bicentennial GPU pack (#68850) pass external validation across WGSL, HLSL, MSL, SPIR-V, and GLSL with 1,228 verified Superopt V6 rewrites. This browser page verifies datasets_manifest.json via WebCrypto SHA-256 before enabling filters and summarizes the sealed offline corpora; multi-megabyte Parquet and JSONL training files remain staged offline and are not embedded inline in static site HTML.
