Model families & verified runs

Local research lines built to test whether small, verifiable models paired with real execution checks can close the reliability gap without opaque cloud dependencies.

  • JFC3P-7B-Oracle (v3 PASS) 48/84 Raw / 49/84 Arm C (+6 over Base), 15/15 longppl preserved, 32.72 ms CUDA 151k Reverse-KL, A1..A5 PASS

    MLP-only LoRA (Q/K/V/O attention frozen) + FRESCO orthogonal gradient projection + Three-Plate Verification Oracle coupled to live buildc/f64 execution. v2's attention-layer drift (40/84, 10/15 longppl) was caught fail-closed and stays published in the evolution table below.

  • PUCT Oracle Search & Merkle Trace (flywheel#566) 6/6 adversarial fault catch + 34.99x RFC 6962 proof-carrying trace compression (0 soundness loss)

    Execution-Oracle-Guided PUCT Verification Tree Search with hard Q_oracle pruning (beating planted high-prior wrong branches) paired with fail-closed Merkle trace compression that rejects any dropped witness or forged root.

  • NOH-4 78.0x lower MSE against baseline neural operator surrogates

    Compact spectral neural operator trained on deterministic fluid, optical, and structural PDE trajectories for real-time physical surrogates inside The Playground.

  • Plato-Key Deterministic geometric representation & symmetry-manifold lookup

    Separates invariant geometric primitives from rendering skins, enabling continuous metamer detection across visual, structural, and acoustic projections.

  • AVTR-4R 4-stage recurrent reasoning & rollback witness

    Explicit state-hash checkpoints across reasoning steps with zero silent drift; any falsified intermediate assertion rolls back to the last verified witness.

  • FRESCO / MoLT / LoopCD Looped compute, stress-rest scheduling & distillation kernels

    Tests recursive depth vs parameter count on commodity single-GPU hardware (RTX 4090 / 24 GB VRAM), publishing null results whenever recursive scaling stalls.

  • BuildLang 1.18M-Record Corpus Engine 1.18M structured syntax, effect-row, and proof records

    Self-verifying compiler training corpus generated and checked directly by buildc so every training pair is type-checked and effect-verified before fine-tuning.

Tier-A evidence firewall

Nothing self-warrants. Every fine-tuned checkpoint is scored head-to-head against its unadapted base model on the same harness, with McNemar paired intervals and retired-null disclosures kept public.

Example honest nulls kept public: (1) JFC3P-7B-Oracle v2 regressed to 40/84 (10/15 longppl) under full-layer LoRA before v3 froze attention heads and recovered 15/15 longppl at 48/84 Raw / 49/84 Arm C; (2) Flywheel Local Coder 14B scored 136/164 (82.9%) vs Qwen 2.5 Coder 14B base at 141/164 (86.0%, p = 0.404) unguided, while coupling the same tier to live buildc lifted BuildLang pass rates from 16.67% to 95.83% (p = 4e-6).
