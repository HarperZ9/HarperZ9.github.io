Verify whether bytes reaching a model, reviewer, or pipeline still match their claimed source; anchor, compare, neutralize embedded authority, audit drift, and mint portable closed-verdict receipts across four implementations.

v1.2.0 adds an optional DeepEval reporter while keeping the witness core zero dependency and authority-incapable.

shipped flagship · v1.2.0 · optional DeepEval reporter · three verdicts only

Three answers. None of them trusted.

MATCHThe file or packet bytes match the recorded digest. It says nothing about usefulness or correctness.
DRIFTAt least one byte-level comparison no longer matches the recorded digest.
UNVERIFIABLEThe file, packet, or manifest cannot be checked. The tool reports the gap instead of guessing.

Run the witness.

Install the public package, run the self-test, then re-run conformance from a fresh checkout when you need source-level evidence.

$ pip install emet[deepeval]
$ emet selftest
$ git clone https://github.com/HarperZ9/emet
$ cd emet
$ python conformance/run.py membrane.py

The DeepEval reporter is optional and lazy. The no-authority witness core remains separate from evaluation reporting.

Limitations kept visible.

The conformance implementations are same author, so they prove that the rules are clear enough to implement in several languages. They do not prove independent authorship, semantic quality, model quality, or third-party adoption.

Its closed verdict records byte agreement, drift, or inability to verify. A human or downstream process still decides what that result means.
