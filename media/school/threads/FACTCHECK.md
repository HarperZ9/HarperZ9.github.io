## Other notes

- `evidence.json` `ours-threads` third claim, "No broken kernel of nine escapes both the output check and the canaries", is wrong twice over. The canaries are part of the output check, and the output check misses two cases. The facts support: "No broken case of nine escapes both the output check (elements and canaries) and the emulator's count of out-of-bounds stores." "nine kernels" in the citation line should be "three broken kernels, nine broken cases".
- `evidence.json` `cuda`: the citation reads "CUDA C++ Programming Guide, release 13.4" and links `docs.nvidia.com/cuda/cuda-c-programming-guide/`. That page is now titled "(Legacy)", says it is "no longer being updated as of CUDA 13.0", and gives 32-, 64- or 128-byte transactions. The 32-byte sentence the film relies on is in the new "CUDA Programming Guide", v13.4.2, `docs.nvidia.com/cuda/cuda-programming-guide/`, section 2.3.4.1; warps are section 1.2.2.2 "Warps and SIMT". `fill_threads_report.mjs` already cites the new guide; `threads.mjs` says "section 1 programming model", which should be 1.2.2.2.
- `evidence.json` `webgpu`: values confirmed against the 15 September 2026 draft. `wgsl`: the draft read was dated 21 September 2026. Its claim, and `spec.wgsl.invalidStore` in `facts.json`, should add the trap outcome and "not limited to" (row 11).
- Typed numbers that should be tokens: "64" (row 7, `grouping.rows.2.wg`), "Crew 2, place 8, crews of 16, element 40" (row 6, `film.offByOne.0`), "nine" (row 14, count of `controls.rows` with kind not "add"), "32" team size (row 16, `spec.cuda.warpSize`), "32 bytes" (row 17, `spec.cuda.transactionBytes`), "eighth" and "eight" (rows 19, 20, `traffic.rows.3.stride`). "4 bytes" and "128 bytes" (row 18) follow from WORD and WARP in `threads.mjs`; acceptable, or derive them.
- `proofs/proof.scene.mjs` labels the contiguous panel "neighbouring cans: one crew, one trip". In the 32-byte model the film uses, that is 4 trips; one trip holds only in the 128-byte model. It is marked "illustration", but it contradicts row 18 on screen.
- The lab's workgroup sizes go up to 256 (`lab.workgroupSizes`). A device created in compatibility mode allows only 128; `openDevice` asks for the default (core) adapter, so this is fine today. Note it if compatibility mode is ever requested.
- Voice: no line gives the chip, a thread or a checker a want or a goal.
