# Front door: archive credits

Each file in this folder is cut from public domain or CC0 material, gathered with open-archives on 23 October 2026. Each line names the source, the licence and the file it became.

- "Astrolabe" by Regiomontanus, via The Metropolitan Museum of Art, https://www.metmuseum.org/art/collection/search/923639. CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/). Used as astrolabe-met-1462-640.webp, the engraving on the home's dial, and astrolabe-met-1462-1200.webp from the front door's first design.
- "Heavenly Bodies" (1920), via Prelinger Archives, https://archive.org/details/Heavenly1920. Public domain. Used as heavenly-boat-480.mp4 and heavenly-boat-poster.jpg, the low-tide loop in the Low Water panel (03:42 to 03:49).
- "2017 Total Solar Eclipse" by NASA/Carla Thomas, via NASA, https://images.nasa.gov/details/AFRC2017-0233-009. Public domain. Used as eclipse-nasa-2017 (the front door's hidden eclipse).
- "Concrete Layers 02" by Rob Tuytel, via Poly Haven, https://polyhaven.com/a/concrete_layers_02. CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/). Used as concrete-layers (the front door's supergraphic bands).
- "Astronomicum Caesareum" by Michael Ostendorfer, via The Metropolitan Museum of Art, https://www.metmuseum.org/art/collection/search/337061. CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/). Used as volvelle-apianus-1540 and paper-apianus-1540 (the front door's dragon wheel and paper).
