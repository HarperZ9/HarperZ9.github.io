# Front door: archive credits

Every file in this folder is cut from public domain or CC0 material, gathered with open-archives on 23 October 2026. Each line names the source, the licence and the file it became.

- "Astrolabe" by Regiomontanus, via met, https://www.metmuseum.org/art/collection/search/923639. CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/). Used as astrolabe-met-1462 (the brass astrolabe behind the form).
- "2017 Total Solar Eclipse" by NASA/Carla Thomas, via nasa, https://images.nasa.gov/details/AFRC2017-0233-009. Public domain. Used as eclipse-nasa-2017 (the hidden eclipse).
- "Concrete Layers 02" by Rob Tuytel, via polyhaven, https://polyhaven.com/a/concrete_layers_02. CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/). Used as concrete-layers (the supergraphic bands).
- "Heavenly Bodies" by Unknown, via ia_prelinger, https://archive.org/details/Heavenly1920. Public domain (http://creativecommons.org/licenses/publicdomain/). Used as heavenly-boat (the Low Water loop, 03:42 to 03:49).
- "Astronomicum Caesareum" by Michael Ostendorfer, via met, https://www.metmuseum.org/art/collection/search/337061. CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/). Used as volvelle-apianus-1540 and paper-apianus-1540 (the dragon wheel and the paper).
