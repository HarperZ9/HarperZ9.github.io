# Licence of this directory

This directory is a copy of reconcile, an engine by the site's author.
`tools/sync-reconcile.mjs` copies the JavaScript sources and the `LICENSE`
file from the reconcile repository.

The copy here carries the `LICENSE` that was current when it was synced, which
is the GNU Affero General Public License 3.0. The reconcile repository is
moving to FSL-1.1-MIT (Functional Source License 1.1, MIT future licence) from
its next version. When that version is published, run the sync again so that
this directory carries the FSL-1.1-MIT copy and its `LICENSE`.

The site's own code that loads this engine stays under the site's LICENSE.
