Figure Drawing Garden (IndieGameJoe)

Post by Indie Game Joe (@IndieGameJoe), 2026-10-25

What it is, and who made it

A game for drawing practice: walk a garden of 3D-scanned sculptures and sketch them, with a dynamic lighting mode for shading practice and model packs.

Parts, layer by layer

  • Features: garden of statues; real sculptures 3D-scanned; dynamic lighting mode; model packs menu (O).
  • Clip: 36 s; mean speed 0.13 widths per second, coherence 0.52 (M); grey-white scenes, a hand sketching (O).

The framework behind it

A tool that turns light into the teacher: the same form under moving light shows how shading works. Light is the additive; the form is the medium.

The same idea in distant fields

  • Plaster cast drawing in academies.
  • Photographic lighting studies (one subject, many lights).
  • Museums with cast courts.

Dual edge

Learning tools can become engagement loops; the canon asks for tools that return time. A study tool should end when the drawing is done.
