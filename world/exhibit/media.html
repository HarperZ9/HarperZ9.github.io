The Mediums Wall

We are here

Seventeen ways a page, a print or a screen has carried a message, rebuilt in code. Each card shows a real object from the archives beside a live swatch you can push. Twelve swatches use the same 1915 photograph, so you can see what each medium does to it. The four screen mediums run on film loops from the Prelinger archive.
