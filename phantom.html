Hardware identity privacy, bounded to authorized systems.

Audit and change reversible hardware-identity surfaces on owned or expressly authorized Windows and Linux systems, with backup and revert.

The public release is cross-platform, but deliberately bounded: Layer 2 only, Windows installer unsigned, and no shipped kernel or firmware capability claim.

Current public maturity.

Release v1.1.0, verified from first-party GitHub release state at 2026-08-26T23:02:02-07:00. Assets include Windows MSI/zip, Linux deb/rpm/tarball, and SHA256SUMS.txt.
Layer Layer 2 only. Layers 1 and 0 are modeled but not shipped as user-facing capabilities.
Windows Registry-backed controls: MachineGuid, HwProfileGuid, MachineId, ProductId, and InstallDate. ComputerName is modeled but deliberately not applied in v1.1.0.
Linux File/interface-backed controls: machine-id, hostname, and physical-interface MAC. Linux apply and revert require root and iproute2 for MAC changes.
Unsigned edge The Windows installer is not code-signed. The Layer 1 driver is unsigned and not functional end to end, so this page does not claim a shipped kernel capability.

Operating boundary.

It is not a fraud tool, not a court-order avoidance tool, and not a general-purpose misrepresentation system. The authorization boundary is part of the product.

Read-only verification commands.

phantom --version
phantom audit

These commands are separated from apply, validate, and revert because they can be used for release or host inspection without intentionally changing system identity state.

State-changing workflow, documented separately.

phantom profile generate <profile-name>
phantom apply <profile-name> --layers 2    # elevated/root; writes Layer 2 controls after backup
phantom validate <profile-name>            # post-change check tied to the chosen profile
phantom revert                             # elevated/root; restores preserved originals

Run the state-changing path only on a host you own or are expressly authorized to test. Preserve the backup and use a named profile placeholder in documentation or review packets until the actual engagement scope supplies a real profile name.
