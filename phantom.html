See and change the hardware IDs your computer exposes.

Phantom helps you inspect and, when authorized, change the hardware identifiers a computer exposes. It works on owned or expressly authorized Windows and Linux systems, saves a backup before changes, and can restore the original values.

phantom · v1.1.1 · Windows + Linux · proprietary · Free / Pro / Enterprise · phantom audit

What it covers

Motherboard serials, disk serials, MAC addresses, GPU device IDs, TPM module IDs, and the machine IDs Windows and Linux keep, are all readable by ordinary software, and most of them survive a clean reinstall. Together they identify the machine. Phantom reads them, replaces them with a consistent profile, and restores the originals when you are done.

Audit, apply, revert

Read what the machine reveals. Generate one internally consistent identity from a seed. Apply it after the originals are backed up, never before: the registry on Windows, the machine-id, hostname, and MAC on Linux. Validate that every source now reads consistently. Revert restores the exact originals from that backup, and so does uninstall.

What it does

See your exposure phantom audit reads and reports every hardware identifier software can see on the machine, across SMBIOS, disk, network, GPU, TPM, display, boot, and the OS identity store: the Windows registry, or the Linux machine-id and hostname. It changes nothing.
A consistent identity, from a seed Generation builds a realistic profile that holds together: disk serials match their vendor's format, MACs use real manufacturer prefixes. One seed reproduces the same identity every time.
Spoof what matters most At Layer 2, apply rewrites what carries the most fingerprinting weight: five Windows registry identifiers from MachineGuid down, or the machine-id, hostname, and MAC on Linux. The wider identifier set is modeled so profiles stay consistent as the deeper layers land.
Reverse it completely Every original value is backed up before the first write. Revert restores them exactly, and uninstall reverts before it removes anything.

Install and run it

Everything is on the releases page with a published SHA256SUMS.txt. Verify the file you got before you install it, because the Windows installer is not code-signed yet.

windows download PhantomSetup-v1.1.1.msi · certutil -hashfile PhantomSetup-v1.1.1.msi SHA256
linux sudo apt-get install ./phantom_1.1.1-1_amd64.deb · or the .rpm, or the tarball's install.sh

On Windows, clear the SmartScreen warning with More info then Run anyway, and accept the UAC and license prompts. Once it is installed, see your exposure before you change anything:

audit phantom audit

Applying changes machine-wide identifiers, so run it from an elevated terminal on Windows, with sudo on Linux. Phantom runs in Free tier immediately, which covers Layer-2 spoofing and up to two profiles.

apply phantom profile generate my-profile · phantom apply my-profile
undo phantom validate my-profile · phantom revert

Tiers

Free covers Layer-2 registry spoofing and two profiles, with no time limit. Pro and Enterprise raise the profile limit, add the background service that reapplies your identity across reboots, and unlock the deeper layers as they ship.

Specifications

Platform
Windows 10 22H2 or Windows 11 23H2 and newer; Linux with systemd. x86-64.
Install
Windows: an MSI, not code-signed yet. Linux: a .deb, an .rpm, or a portable tarball. Elevation on Windows, root on Linux for apply and revert.
Applies at Layer 2
Windows: MachineGuid, HwProfileGuid, MachineId, ProductId, InstallDate. Linux: machine-id, hostname, and the MAC of each physical interface.
Models, not yet applied
SMBIOS, disk, network, GPU, TPM, display, and boot identifiers, for the Layer 0 and Layer 1 paths.
Reversibility
Originals backed up before the first write; revert and uninstall both restore them exactly.
Persistence
PhantomService reapplies the active profile across reboots (Pro and Enterprise).
Licensing
HMAC-signed keys bound to one hardware fingerprint. Free, Pro, Enterprise.
Phone-home
Off unless you set a callback URL. No fingerprint, profile, or identity ever leaves the machine.
Store
Profiles, config, backup, and license live under %ProgramData%\Phantom on Windows, /var/lib/phantom on Linux, shared by the CLI and the service.

Current release

It adds a getting-started guide and the first part of a local boundary gateway to v1.1.0, where the Layer-2 path was tested end to end on fresh Windows and Linux VMs, including a reboot that brought a spoofed MAC back through the service.
