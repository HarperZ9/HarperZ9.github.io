Small tools for shipping a release.

Single-purpose tools I run before putting something out: sweep a repository for leaked keys and missing files, index the review records a project produces, check a release source record, redact secrets from file and shell output, and map every repository in a workspace.

6 packages on PyPI · the rest on GitHub

On PyPI

proof-surface v0.1.0: checks an agent action against the permission behind it and returns allow, deny or needs-human. its own page →

public-surface-sweeper v0.1.3: run before a release to confirm required files are present and sweep for keys, passwords and tokens. sample report →

repo-proof-index v0.2.0: builds a reviewer index of the review packets, receipts and contracts in a project.

model-provenance-validator v0.1.1: checks the source record for a model or release and redacts credential-like values from its output.

index v2.13.0, as index-graph: maps every repository in a multi-repo workspace. its own page →

build-color v1.0.2: color measurement and conversion, with its own page.
