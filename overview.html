Choose by capability.

Names are easier to remember after the job is clear. These groups describe the current public registry; they are not product tiers.

Run and coordinate agent work

Routing, team execution, endpoint control, tool wiring, and memory.

  • ForumRoute and run agent fleets with budgets, approval gates, checkpoints, and a causal ledger.
  • RelayProvide a zero-dependency coding agent for local, subscription, API, and cloud endpoints with permission gates and a hash-chained run ledger.
  • PlexusDiscover declared tool capabilities and derive inspectable producer-consumer wiring plans.
  • MnemeProvide layered agent memory with provenance, reproducible hybrid recall, drift detection, and audited forgetting.

Gather, map, and test evidence

Source capture, workspace structure, and bounded verdicts.

  • GatherCapture web, scholarly, document, browser, OCR, video, and audio material into provenance-bearing research records.
  • IndexBuild offline repository and workspace maps, dependency graphs, symbols, and bounded context artifacts from file-line evidence.
  • CrucibleTest falsifiable claims against supplied measurements and emit MATCH, DRIFT, or UNVERIFIABLE outcomes.

Build visual and retro systems

Deterministic creative output, browser experiments, and restoration records.

  • Studio EngineGenerate deterministic shader, sound, motion, preview, and receipt-bearing creative-world packets.
  • Retro EngineServe as the Retro Systems Lab play pillar: an interactive browser studio for owned pixel, palette, shader, and CRT experiments.
  • Engine RevivalServe as the Retro Systems Lab preserve pillar: a public MIT evidence spine for historical engine and rendering-library revival records.
  • BRender ArchivalServe as the Retro Systems Lab verify pillar: a specific BRender restoration surface that stays separate from generic Retro Engine media.

Retro systems cross into the wider workshop without losing their history.

The retro lane keeps three kinds of evidence separate. Historical restoration proof comes from the named repository, creative browser output remains creative output, and preservation records say exactly what was reviewed.

  1. PreserveEngine Revivalmaintains the public restoration evidence spine
  2. VerifyBRender Archivalholds the specific BRender boundary and receipts
  3. PlayRetro Engineturns owned pixels, palettes, shaders, and CRT studies into browser experiments
  4. ReuseFlywheelcan carry bounded outputs into a larger, reviewable workflow
