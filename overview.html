Choose by capability.

Names are easier to remember after the job is clear. These groups are navigation labels in the current public registry; they are not product tiers or dependency claims.

Run and coordinate agent work

Routing, team execution, endpoint control, tool wiring, and memory.

  • ForumRoute and run agent fleets with budgets, approval gates, checkpoints, and a causal ledger.
  • RelayProvide a zero-dependency coding agent for local, subscription, API, and cloud endpoints with permission gates and a hash-chained run ledger.
  • PlexusRead declared interop manifests, derive producer-consumer wiring and dependency plans from those declarations, emit inspectable graphs and pipeline scripts, expose the mesh over MCP, and optionally probe a registered Flywheel lane when explicitly requested.
  • MnemeProvide layered agent memory with provenance, reproducible hybrid recall, drift detection, and audited forgetting.

  • GatherCapture web, scholarly, document, browser, OCR, video, and audio material into provenance-bearing research records.

  • CrucibleTest falsifiable claims against supplied measurements and emit MATCH, DRIFT, or UNVERIFIABLE outcomes.

Registry facts used for review.

This block mirrors the current registry wording for the systems most often used in hiring, collaboration, and technical review.

  • FlywheelRun a verified-inference platform and native desktop client in which models perceive through witnessed tools, act through permission gates, journal their work, and re-check outcomes through integrated lanes.
  • IndexDerive offline repository wikis, dependency and symbol graphs, workspace atlases, context envelopes, architecture checks, and freshness evidence from file-and-line-grounded source.
  • GatherExtract and crawl difficult research sources, including JavaScript-rendered pages, authenticated APIs, scholarly records, PDFs, OCR, audio, video, feeds, and local documents; store content-addressed corpora and attach re-checkable provenance to every item.
  • ForumRoute, plan, and execute multi-agent dependency waves across model-neutral backends with budgets, approval gates, crash-safe checkpoints, delivery contracts, service surfaces, and a replayable causal ledger.
  • CrucibleRegister a thesis as falsifiable claims, steelman the tests, measure each claim against replayable oracles, refine the weakest axis, and emit re-checkable MATCH, DRIFT, or UNVERIFIABLE verdicts.
  • RelayRun a permission-gated coding agent across local models, subscription CLIs, APIs, gateways, and cloud endpoints, with failover, acceptance checks, resumable sessions, MCP access, and a hash-chained trajectory.
  • PlexusRead declared interop manifests, derive producer-consumer wiring from those declarations, emit inspectable plans and scripts, and probe a registered Flywheel lane only when explicitly requested.
  • MnemeProvide deterministic four-tier agent memory with hybrid retrieval, per-memory provenance, reproducible rankings, source-drift detection, temporal and multi-user memory, audited forgetting, and MCP access.
  • Studio EngineGenerate, critique, refine, and preserve replayable creative worlds from one expression algebra that emits shader programs, audio graphs, motion timelines, previews, measurements, and receipts.
  • Retro EngineRun a browser studio that accepts images, drawing, GLSL, and audio traces; applies pixelation, hardware palettes, ordered dithering, early-3D shading, CRT processing, and stackable effects; then exports images, patches, MIDI, relief or disc data, and Loom handoffs.
  • Engine RevivalMaintain public-safe metadata, schemas, validators, target matrices, reproduction recipes, evidence packets, and reports for reviving historical game engines, SDKs, rendering libraries, CGI toolkits, and studio technology.
  • BRender ArchivalRebuild and document Argonaut BRender from its public MIT source with an out-of-tree CMake harness, a 21-rung native verification ladder, reproducible render captures, provenance records, and public-safe release packaging.
