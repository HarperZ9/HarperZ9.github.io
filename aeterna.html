Hook Present. Draw over everything.

Aeterna is a DX11/DX12 overlay framework. A proxy DLL intercepts the graphics Present call via MinHook and renders an ImGui overlay into the application's swap chain. For runtime instrumentation, debugging, and visual inspection of DirectX applications.

The overlay that sees what the renderer draws.

Aeterna · private · C++ · DX11/DX12 · MinHook · ImGui

Rendering pipelines are opaque from outside the process.

Understanding what a DirectX application is doing at the GPU level requires being inside the render loop. External tools see the final composite; internal instrumentation sees each draw call, resource bind, and state change. Aeterna provides the hook point: a proxy DLL that interposes on the swap chain's Present call and renders diagnostic or custom overlay content before the frame reaches the display.

How it works.

Proxy DLL Placed alongside the target executable. The application loads it instead of the system DLL, and Aeterna forwards every call to the real implementation after interposing on the ones it needs.
MinHook interception Hooks the IDXGISwapChain::Present vtable entry. The hook runs before the frame is presented, giving the overlay a window to draw into the back buffer.
ImGui overlay Renders diagnostic panels, inspection tools, and custom UI using Dear ImGui. The overlay composites into the application's swap chain, so it appears on top of the rendered frame.
DX11 and DX12 Separate code paths for each API. DX11 hooks Present on the DXGI swap chain. DX12 hooks Present and manages its own command allocator and descriptor heap for the overlay render pass.

Components.

ComponentFunction
proxy_dllDLL that forwards system calls and interposes on swap chain creation and presentation.
hook_engineMinHook-based vtable patching. Installs and removes hooks at DLL attach/detach.
dx11_backendDX11 render path. Creates a render target view from the back buffer and draws the ImGui overlay.
dx12_backendDX12 render path. Manages its own command allocator, descriptor heap, and render target for the overlay pass.
imgui_layerImGui integration. Handles input forwarding, font atlas, and overlay panel layout.
