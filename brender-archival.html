BRender Archival.

BRender Archival rebuilds Argonaut BRender from a pinned public MIT source checkout. The project supplies an out-of-tree CMake harness, a 21-rung native verification ladder, reproducible render captures, provenance records, and public-safe release packaging.

BRender Archival v0.1.1 is public at release v0.1.1, with main pinned to 11b5a8d539e911a9c07991b751402a7d51bf1bde. The repository is AGPL-3.0-or-later; upstream BRender MIT source is referenced, not vendored.

Evidence boundary.

Verified public release

BRender Archival public main and release v0.1.1 both resolve to 11b5a8d539e911a9c07991b751402a7d51bf1bde. The release records 21/21 native CTest targets and a measured release media source run. The repository is AGPL-3.0-or-later, and upstream BRender MIT source is referenced from a public checkout rather than vendored.

Does not prove: completed textured TIA output, x64 readiness, production readiness, adoption, endorsement, performance, legal completeness, or vendored upstream source or assets.

Companion renderer boundary

Retro Engine is a companion renderer, not BRender proof. generic Retro Engine output is not BRender evidence. Engine Revival can preserve release state, but the verify claim remains owned by BRender-specific receipts.
