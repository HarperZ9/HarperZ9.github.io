BRender Archival

BRender Archival rebuilds the Argonaut BRender engine from its public MIT source, runs it through a 21-stage native test ladder, captures renders, and packages the build harness, test transcripts and checksums without copying the upstream source.

What the release contains

Release v0.1.1 is built from commit 11b5a8d539e911a9c07991b751402a7d51bf1bde and passes 21 of 21 native CTest targets. It references the upstream BRender MIT source from a public checkout. The repository itself is AGPL-3.0-or-later.
