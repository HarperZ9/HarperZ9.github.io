Authorization boundary.

Public tools may be read and run within their licenses and documented limits. Private security practice begins only after written scope and lawful authority are established. This page does not publish source for private systems, counterparties, sensitive deployment detail, target specifics, or operational methods.

A request without a lawful basis receives only public material.

Data-backed claims.

The claim registry is public: security-tools.json. It records purpose, version, maturity, source, install or entry route, verification command, evidence date, limitations, and authorization boundary for each promoted item.
