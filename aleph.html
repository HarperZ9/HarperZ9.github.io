PROJECT TELOS PRIVATE-LINE PLATFORM

One checkpoint. Ten working tools.

Checkpoint is the public contract for the Project Telos private line: Checkpoint (Aleph), Ledger (Sofer), Lab (Seed), Vault (Kun), Runtime (ORCA), Isomorph, Array, Bounds, Phantom, and Aeterna. It verifies presentation, package shape, MCP readiness, CLI contracts, provenance receipts, and release state before anything is described as ready.

WHAT IT IS

A release checkpoint for tools that have to be usable alone or inside a larger surface.

The live public flagships now use a simple pattern: direct purpose, visible artifact, installation path, reason it matters, and current status. Checkpoint brings the same standard to the private line. Ten tools, each with its own repository, each checked by the same release gate.

The private-line standard is concrete: command surfaces must be inspectable, package metadata must agree with the docs, MCP or host-neutral integration must be declared, graphics must match the Project Telos presentation language, and every readiness claim must resolve to a receipt.

THE TEN UNITS

Each tool has a clear job.

Checkpoint

Aleph. Release gate for the private line: docs, package contracts, MCP declarations, CI state, and receipt checks.

Ledger

Sofer. 74-package orchestration suite for warfare intelligence, law enforcement, child safety, CBRN, financial crime, infrastructure defense, and cyber operations. MCP bridges and action receipts.

Lab

Seed. C++23 red-team assessment runtime with ATT&CK-mapped verification. 59 modules, 3,065 tests. Nested in Array.

Vault

Kun. Local access-recovery vault with redacted diagnostics, rotation notes, and operator runbooks. Path-only receipts, never raw credentials.

Runtime

ORCA. Native operator runtime for module execution, local run state, release provenance, and package handoff.

Isomorph

Isomorph. Inference boundary research infrastructure. Transform pipeline, probe engine, refusal substrate, leakage accounting, and findings engine.

Array

Array. Offensive assessment platform. Campaign planning, fixture orchestration, containment, and receipt-backed results. Seed nested as the assessment engine.

Bounds

Bounds. Trust verification at every scope. Agent intent-drift auditing, runtime sensors, guard layers, release-readiness scanning, and proof index.

Phantom

Phantom. Hardware identity privacy for Windows and Linux. Audit, generate, apply, revert. Shipped v1.1.0.

Aeterna

Aeterna. DX11/DX12 overlay framework. Proxy DLL hooks Present via MinHook, renders ImGui overlay for runtime instrumentation.

WORK WITH IT

Private by inquiry, not cryptic by default.

A private-line tool can still be readable. The public promise is deliberately plain: Checkpoint makes the private line shippable by forcing each tool to say what it is, how it is operated, which receipts support the claim, and which boundary keeps sensitive behavior out of public documentation.
