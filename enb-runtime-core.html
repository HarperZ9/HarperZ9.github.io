Identify an already-loaded ENBSeries host, validate its SDK surface, queue callbacks outside callback context, coordinate save quiescence and reapplication, and gate a fail-closed Skyrim engine bridge.

  • graphics plugin inspection

  • callback and save-lifecycle events
  • optional Skyrim bridge state

Outputs

  • queued callback dispatch

  • fail-closed bridge status
