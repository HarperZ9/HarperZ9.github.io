Sofer · private · Python · proprietary · MCP bridges · action receipts

Operational tools without audit trails are liabilities.

Intelligence analysis, law enforcement workflows, child safety investigations, and CBRN assessment all require tools that do real work. They also require proof that the work was done correctly. Sofer provides both: operational capability and an action-receipt ledger that records every decision, query, and result.

Each of the 74 packages covers one bounded function. Each function produces a structured receipt. The receipts compose into audit trails that survive review.

Spec.

Runtime
Python. Each package is independently installable with its own test suite.
Integration
MCP bridges expose package functions as tool surfaces. Compatible with any MCP-capable host.
Receipts
Every action produces a structured JSON receipt. Receipts are append-only, timestamped, and operator-attributed.
Testing
All 12 package groups have test files (57 to 235 lines each). Tests run against synthetic data.
Distribution
Private repository. Domain-specific packages available under authorization for qualifying organizations.
