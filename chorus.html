Zain Dana HarperChorus

Discourse synthesis, bounded by receipts.

Chorus turns a captured comment or thread corpus into weighted, clustered, re-checkable discourse digests. Version 0.3.0 adds a source-change review gate for deciding whether current gathered sources still match a reference set.

It is a standalone public system that can read Gather corpora. Its optional model overlay is separately provenanced and excluded from the deterministic receipt, and the v0.3.0 GitHub release added the source-change gate. Version 0.3.1 is on PyPI as chorus-discourse.

Install Install from PyPI with python -m pip install chorus-discourse==0.3.1. First use: chorus decision <current> --reference <reference> --task "Check whether sources changed".
Boundary A digest or source-change decision is a structured reading of the provided corpus and source packs. Lexical clustering is not semantic understanding; the English-only sentiment pass does not resolve sarcasm, irony, or context. The output does not prove source completeness, public opinion, motive, identity, or factual correctness outside the captured material.

Where it fits.

Use Chorus when the material is already captured and the question is how themes, disagreement, source changes, and evidence limits should be represented without pretending the digest is the whole public record.

View it in the system catalog or start with Gather when the source material still needs to be collected.
