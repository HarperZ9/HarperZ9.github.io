Zain Dana HarperChorus

Discourse synthesis, bounded by receipts.

Chorus turns a captured comment or thread corpus into weighted, clustered, re-checkable discourse digests that rank themes, surface dissent, and identify genuinely contested topics.

It is a standalone public system and a Gather-adjacent research tool. Optional model overlays remain separately provenanced.

Current public record.

Product type Discourse synthesis system.
Implemented work Weighted lexical theme clustering, controversy ranking, receipts, Gather-corpus input, and an optional separately provenanced model overlay.
Evidence Public source identifies active 0.1.0 work. No PyPI package or GitHub release is claimed.
Boundary A digest is a structured reading of the provided corpus. It does not prove source completeness, public opinion, motive, identity, or factual correctness outside the captured material.

Where it fits.

Use Chorus when the material is already captured and the question is how themes, disagreement, and evidence limits should be represented without pretending the digest is the whole public record.

View it in the system catalog or start with Gather when the source material still needs to be collected.
