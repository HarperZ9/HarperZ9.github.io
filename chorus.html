Summarize a comment thread by theme.

Chorus turns a captured comment thread or corpus into ranked, clustered theme digests, and checks whether a set of gathered sources has changed since a reference set.

See it work, step by step: an animated walkthrough with the real commands and output from the repository.

0.3.1 on PyPI · latest GitHub release v0.3.0

Install and try it

$ python -m pip install chorus-discourse==0.3.1
$ chorus decision <current> --reference <reference> --task "Check whether sources changed"
Digests Clusters comments with deterministic hashed-TF-IDF vectors, scores sentiment with an English-only literal lexicon, and ranks themes and the points people disagree on. It reads Gather corpora directly, including Gather feed entries since 0.3.1. An optional model overlay can add commentary; it is excluded from the deterministic receipt, so the core digest reproduces exactly.
Source-change check chorus decision, or chorus.decision over MCP, compares a current source pack with a reference and returns MATCH, DRIFT or UNVERIFIABLE. Use it before reusing a digest or release note. See the 0.3.0 changelog.
Releases PyPI serves chorus-discourse 0.3.1. The 0.3.1 tag has no GitHub release; GitHub release v0.3.0 carries the wheel, the source archive and a checksum file.
Limits Sentiment is English and literal, so sarcasm and irony can be missed. Clustering is lexical.
