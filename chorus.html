Zain Dana HarperChorus

Discourse synthesis, bounded by receipts.

Chorus turns a captured comment or thread corpus into weighted, clustered, re-checkable discourse digests that group themes, surface literal disagreement in captured comments, and preserve source-linked receipts.

It is a standalone public system that can read Gather corpora. Its optional model overlay is separately provenanced and excluded from the deterministic receipt.

Install Download chorus_discourse-0.2.0-py3-none-any.whl, then run python -m pip install chorus_discourse-0.2.0-py3-none-any.whl. The GitHub release also includes a source distribution and checksums; no PyPI release is claimed.
Boundary A digest is a structured reading of the provided corpus. Lexical clustering is not semantic understanding; the English-only sentiment pass does not resolve sarcasm, irony, or context. The output does not prove source completeness, public opinion, motive, identity, or factual correctness outside the captured material.

Where it fits.

Use Chorus when the material is already captured and the question is how themes, disagreement, and evidence limits should be represented without pretending the digest is the whole public record.

View it in the system catalog or start with Gather when the source material still needs to be collected.
