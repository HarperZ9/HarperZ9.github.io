Engine Revival

Engine Revival is a Python tool for building, checking and publishing metadata about revived historical engines. It can also generate an out-of-tree BRender CMake build harness from a public checkout.

Release v0.1.0

What the release contains

Release v0.1.0 is built from commit 0af6d527860a63c418b5775dc0efe9ba89557604 under the MIT license. Its own materializer generates a 12-target BRender build scaffold.

The full 21-target BRender build and its test results come from BRender Archival v0.1.1, which Engine Revival imports as a record.
