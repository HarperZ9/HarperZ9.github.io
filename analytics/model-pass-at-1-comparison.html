164-task model pass@1 comparison

Two 14B coding models took the same 164 code-completion tasks through the same harness, with one greedy try at each task.

Measured model comparison28 August 2026

How many of the 164 tasks each model passed on its first try

Base Qwen 14B passed 141 of the 164 tasks and Flywheel 14B passed 136, a gap of 3.05 points that is not statistically significant.

How we know: the comparison
Does not prove
This result does not show a statistically significant improvement, general coding superiority, agentic reliability, production readiness, or independent validation.
Limits
The base artifact digest is not pinned in this result file. The result covers one 164-task code-completion suite and does not measure agentic tool use. Hardware, runtime version, latency, cost, and resource use are not recorded in this result file.
Method
Same 164 code-completion tasks, same harness, pass@1, greedy decoding, temperature 0. Each bar is the share of the 164 tasks a model passed on its first try, on a scale that starts at zero.
Test
Flywheel 14B was 3.05 percentage points lower. McNemar test on the paired outcomes: continuity-corrected χ²=0.696, p=0.404, significant at 0.05: no.
