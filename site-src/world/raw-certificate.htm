Download the binary for your system from the 0.8.0 release, check it against the published hashes, and point it at an empty folder. A 256 by 256 frame takes about a quarter of a second. The release is still named raw-native. It ships the CPU, Direct3D 12 and WebGPU builds; the Vulkan path is in The Playground’s source and was added after 0.8.0.

# check the download, then render the default view

raw_native_cli --out ./out --width 512 --height 512 --eye 0,9,3 --target 0,0.5,0
raw_native_cli --out ./out --prev-eye 4.3,4,5.7

The certificate

  
A certificate is a JSON file with a claim, a verdict, the oracle that judged it and the numbers behind the verdict. The verdict is verified, refuted or unverifiable. A channel with no data is written as null.

  
You can check one in two ways. From 0.3.0 the run writes its ambient occlusion as 32-bit floats beside a coverage mask, and raw_native_cli verify recomputes the error from those files alone. Or run the same command yourself, because the output is deterministic: the default frame and its certificate hash the same with MSVC 19.50 on Windows, with GCC 13.3 on Ubuntu and from the WebAssembly build, locally and on GitHub’s build runners. The renderer also measures exactly how many bytes the frame needs, renders again inside that budget, and refuses any allocation past it. A second certificate records whether the budget held.

Scope and speed

  
    
    
  • There is one built-in test scene and no model loader yet.
    • 
    
  • The ray-traced reference uses 64 samples per pixel, so it shows visible grain.
    • 
    
  • The screen-space method is a simple one, which is why most views come back refuted.
    • 
    
  • The default tolerance is 0.12 RMSE. --tolerance changes it, and the certificate records the value used.
    • 
    
  • A full render with the ray-traced reference takes about 0.26 seconds at 256 by 256 and 1 second at 512 by 512 on one thread of an Intel Core i7-13700KF, natively or in WebAssembly. Times on this page depend on your machine.
    • 
    
  • On an NVIDIA RTX 4090 in Chrome, the GPU draws a 512 by 512 frame with every channel in about 14 milliseconds, and all 16 GPU certificates in the release evidence say verified. The CPU reference that checks each GPU frame still takes its full time, so a GPU render on this page is not faster end to end.
    • 
    
  • Without WebGPU this page runs the single-threaded CPU build. The threaded WebAssembly build ran about eight times faster on the same machine, but browsers allow it only on pages sent with cross-origin isolation headers, and GitHub Pages cannot send them.
    • 
    
  • Matching hashes were checked on x86-64 with two compilers and the WebAssembly build. Other processors and compilers are untested.
    • 
  






  
Where it came from.

  
The name comes from RAW, a Direct3D 11 effects platform I wrote for Skyrim SE: a proxy library that took over a closed game’s frame and added its own lighting passes mid-picture. That taught me how a frame is built and how quickly an effect can look right while being wrong. The native renderer keeps the lesson and drops the game. It owns its whole frame, and every frame carries a check against a reference. The Skyrim code stays public. Work on it is paused, and I plan to return to it.

C++23, built from the standard library and its own headers. The rasterizer, both ambient occlusion methods, the reconcile step, the certificate writer, the verifier and the bounded memory arena each have their own tests, 32 in all.
