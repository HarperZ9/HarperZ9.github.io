Model behavior is opaque until you measure it.

Frontier models accept or refuse, reveal or withhold, depending on context, framing, and provider policy. Understanding that behavior requires systematic probing: the same request presented under controlled variations, with each response captured, classified, and reduced to a finding. Isomorph is the infrastructure for that work.

The transform pipeline varies the input. The probe engine runs the variations. The findings engine reduces the output.

What it does.

Transform pipeline Takes a probe and produces controlled variations of it: vocabulary modulation, context framing, authority presentation. Each variation isolates one variable so the response difference is attributable.
Probe engine Runs probe sets against inference endpoints under controlled conditions. Records the full request/response pair, latency, refusal signals, and provider metadata. Reproducible by design.
Leakage accounting Tracks what information crosses model boundaries in both directions. Classifies leakage by type (context bleed, instruction leak, training data surfacing) and logs it to a structured ledger.
Findings engine Reduces raw probe results to structured findings: refusal patterns, boundary locations, sensitivity gradients. Produces deterministic reports from the same probe data.

Spec.

Runtime
Python 3.10+. Standard library for core. Optional dependencies for specific provider integrations.
Authorization
Environment-native. Machine fingerprint (SHA-256 of node + platform + arch) bound to operator identity and capsule.
Probes
Declarative probe definitions. Each probe specifies input template, variation axes, expected response class, and acceptance criteria.
Findings
Structured JSON. Each finding carries the probe ID, variation parameters, response classification, and confidence interval.
Audit
Append-only JSONL. Every probe execution, finding derivation, and authority event recorded.
Distribution
Private repository. Authorized research use only.
