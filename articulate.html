Articulate

A writing checker that runs on your own computer.

In short

Articulate flags named prose patterns, such as hedging, filler words and stock phrases, for editorial review. Its checks run on your own computer with no network connection. This site checks its pages with it.

Install it · Source on GitHub · PyPI

What it is

Articulate checks prose locally for named writing patterns and reports where they occur. Published version 0.5.0 includes detector labels and a texture score; neither establishes who or what wrote a text. Its optional editor sends the draft to a hosted model through the Claude command-line tool.

Each check runs in a writing mode, such as a memo that argues a case or technical documentation that explains. The mode sets which patterns count and how strictly. Fiction, memoir, screenplays and poetry each get their own reading. Under a fiction mode, a character's quoted line is never scored as the author's prose.

Flywheel 1.1.0 bundles Articulate 0.5.0 as one of its lanes. Its installed-app check exercised score and check, but not the hosted editor. The system map shows where it sits among the other tools.

Install and run a check

pip install articulate-writing
articulate check notes.md --mode technical-docs/explain --gate

Pick the mode that fits the text. articulate modes lists them all. With --gate, the command exits with 1 when the text is blocked, so a script or a CI job can stop on it. The core needs nothing beyond Python's standard library.

One example check

This sentence went in:

It is important to note that this release really represents a significant step forward. Arguably, the new cache could potentially make builds faster in many cases.

Articulate blocked it with four findings. Each finding also prints the line it came from, cut here for width.

[articulate] notes.md [technical-docs/explain]: 1 high, 3 medium (blocked)  texture 0/100
  L1 [HIGH filler-intensifier] genuinely / really / truly / actually
  L1 [MEDIUM throat-clearing] throat-clearing opener
  L1 [MEDIUM hedge-stack] stacked hedge
  L1 [MEDIUM throat-clearing] worth-noting preamble

A rewrite that names the change and gives a measured number passes the gate. The numbers here are made up for the example.

This release adds a build cache. On our test project, a clean build took 41 seconds and a cached build took 9.
[articulate] notes.md [technical-docs/explain]: unverifiable (below the signal floor)  texture 0/100

The command exits with 0. The word unverifiable refers to the texture score: the example is below the tool's signal floor. Neither a score nor an unverifiable result establishes authorship.

What a clean check tells you

A clean check means none of the patterns Articulate knows appeared in the text. It says nothing about whether the writing is true or clear, so a reader still needs the sources. The documentation states that Articulate is not a tool for evading AI detection. Writing quality is the goal, and a detector score is a side effect it never aims at.

Receipts

A receipt records a check so that anyone can replay it later against the same file.

articulate receipt notes.md --mode technical-docs/explain --redact drop > notes.receipt.json
articulate verify notes.receipt.json notes.md

The replay gives one of three answers. Match means the file gives the same findings again. Drift means the same text under the same rules now gives different findings. Unverifiable means the replay cannot run as recorded, for example because the file changed after the receipt was made. With --redact drop, the receipt keeps no verbatim text from the file. It still records which rule fired on which line, and a rule named after a short word list narrows the flagged word to that list.

Editing

Three tools read and rewrite prose. Judge names problems a pattern rule cannot see, such as a claim with no position behind it. Fix rewrites a passage to the standard and checks its own result. Polish repeats until the prose clears a bar for concreteness, commitment, economy, rhythm and one restatable fact per paragraph. They run through articulate-mcp, the MCP server that comes with the package, and use the claude command-line tool (Claude Code) to send the draft to a hosted model. The local-only claim covers prose checks and receipts, not these editing calls.

In an editor, the articulate-lsp server shows findings inline in any editor that speaks the Language Server Protocol, such as VS Code, a JetBrains IDE or Neovim.

The later fairness check failed

Version 0.5.0 remains the published release. Later source removes authorship language and records a failed confirmatory release gate; version 0.6.0 is not published. That source change does not alter the installed 0.5.0 package.

Under strict profiles on the PERSUADE 2.0 school-essay corpus, the evaluated ruleset blocked 80 of 1,330 learner essays and 1,889 of 13,467 other essays. The learner-minus-other gap was -8.0 percentage points, with a 95% interval of [-9.3, -6.5]. The gate checks differences in either direction and failed; rule-level and wrapping checks also failed.

The default profile blocked none of the essays, which does not clear the failed gate. The learner label is a school classification; first language was not measured. These results establish neither authorship nor the cause of the group difference. Read the confirmatory result and its limits before relying on the checks.

Releases

Articulate 0.1.0 reached PyPI on 18 September 2026. Version 0.4.1 followed on 24 September 2026. Versions 0.4.2 and 0.5.0 both shipped on 26 September 2026. In 0.5.0 the editing tools start the claude command-line tool (Claude Code) in a private empty folder with user settings only, so a document folder cannot run commands through them. The detector and its findings are the same as in 0.4.1.

  • The no-network claim rests on the project README, which says the detector never touches the network, and on a search of the 0.4.1 check, receipt and command-line code, which found no network library imported. The editing tools call a language model, so they are outside that claim.
