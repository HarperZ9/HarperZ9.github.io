BuildLang BLDLNG

BuildLang means the language, its compiler buildc and its package registry; it is not a build system.

BuildLang 1.14.0

A compiled language where a function's type lists what it may touch. The compiler proves the laws you write beside the code and builds native programs through C.

cargo install buildlang --version 1.14.0 --locked

See it workThe registry, laws and the C pathSource

Verified 12 November 2026: version 1.14.0 is the latest GitHub release of HarperZ9/buildlang (10 November 2026) and the current crates.io version of buildlang.

Flywheel THEFLYWHEEL

Flywheel names the checking work: Flywheel checks answers, CMMNS reads public replies, Articulate checks prose. Each shows its evidence; none decides for you.

Flywheel 1.9.0

Check any model's answer against the source that decides it, and keep every step as a receipt: a record of each step's inputs, output and hashes that anyone can recheck offline, not a log of what the model claimed.

pip install flywheel-verify, then flywheel up

See it workWatch a check, a tamper and a refusalSource

Verified 12 November 2026: version 1.9.0 is the latest GitHub release of HarperZ9/flywheel (15 October 2026) and the current PyPI version of flywheel-verify.

Engine THEPLYGRND

The engine means raw-native, which renders, and Superframe, which composes; together they are THE PLAYGROUND.

raw-native 0.8.0

A renderer that draws each frame twice, on the CPU reference and on the GPU, and certifies whether they agree. Its light comes from radiance cascades: light gathered by rings of probes, each ring reaching farther at coarser detail, an approximation checked against a traced reference.

Download raw-native-0.8.0-windows-x64.zip from the release

See it workRender the frame, then check itSource

Verified 12 November 2026: version 0.8.0 is the latest GitHub release of HarperZ9/raw-native (14 October 2026), and raw-native-0.8.0-windows-x64.zip is attached to it.

Superframe 0.2.0

One seed, written in plain words, comes back as paint, living type, lines, carved material, sound and touch. It is deterministic: the same words and seed give the same bytes on every run, not just a similar picture.

git clone https://github.com/HarperZ9/superframe, then npm run make (Node 24 or later)

See it workOne recipe in every mediumSource

Verified 12 November 2026: version 0.2.0 is the latest GitHub release of HarperZ9/superframe (28 October 2026).
