The Playground

The Playground is the rendering engine and the creative suite built on it. One seed comes back as paint, living type, lines, carved material, sound and touch, and the renderer draws each frame twice, on a CPU reference and on the GPU, and says whether they agree.

What is inside The Playground
  • The core. One seed, written in plain words, rendered in every medium; the same seed gives the same piece.
  • The native renderer. C++ on Direct3D 12, Vulkan and WebGPU, moving to BuildLang a module at a time.
  • Motion. Scenes as pure functions of time, for films and for pages. The walk through the places further down this page runs on it.
  • Type. Living type, lettering, and the house typeface as static and variable fonts.
  • Sound. Instruments built as physical models, a composer that writes from a seed, and measures that stand in for listening.
  • Study tools. Distill; the palette, shape, geometry and rhythm of a picture; checks for image, motion and type.
  • Materials and measured data. Spectral material records and physical constants, each with its source.
  • Makers. Loom drafts, plotter sheets, voxels, fractals, and pictures reduced the way old hardware reduced them.
  • Low Water. The game made with it, as its full-scale demonstration.

Flywheel THEFLYWHEEL

Flywheel is an AI workstation and coding harness for any model, with runs you can recheck. CMMNS, which reads public replies, and Articulate, which checks prose, sit beside it. Each one shows its evidence and leaves the decision to you.

Flywheel 2.0.0

An AI workstation and coding harness that you host yourself. It runs any model, hosted or local, behind one interface, with a desktop assistant, a coding agent that works in your own folders and connected tools for research, memory and writing. What sets it apart: every step is kept as a receipt: a record of each step's inputs, output and hashes that anyone can recheck offline, not a log of what the model claimed.

pip install flywheel-verify, then flywheel up

The Playground THEPLAYGRND

The Playground is a rendering engine that turns one description into picture, type and sound. Its parts are the native renderer, Superframe at the core, the instruments and study tools, and Low Water, the game made with it.

The native renderer 0.8.0

The part of The Playground that renders frames in C++ on Direct3D 12, Vulkan and WebGPU, released as raw-native. It draws each frame twice, on the CPU reference and on the GPU, and certifies whether they agree. Its light comes from radiance cascades: light gathered by rings of probes, each ring reaching farther at coarser detail, an approximation checked against a traced reference.

Download raw-native-0.8.0-windows-x64.zip from the release

See it workRender the frame, then check itSource

Verified 21 November 2026: version 0.8.0 is the latest GitHub release of HarperZ9/raw-native (14 October 2026), and raw-native-0.8.0-windows-x64.zip is attached to it.

Superframe 0.3.0

The core of The Playground. One seed, written in plain words, comes back as paint, living type, lines, carved material, sound and touch. It is deterministic: the same words and seed give the same bytes on every run, not just a similar picture.

git clone https://github.com/HarperZ9/superframe, then npm run make (Node 24 or later)
