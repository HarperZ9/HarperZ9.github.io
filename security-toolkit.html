The utilities

Each links to its public repository.

Public Surface Sweeper source. Entry: public-surface-sweeper . --summary. Try it on the sample: public-surface-sweeper examples/clean-repo. It checks release hygiene only; use a vulnerability scanner for dependencies and exploits.
Model Provenance Validator Model Provenance Validator checks JSON records that link a model or release claim to its sources and retrieval dates, redacts credential-like values from its output, and can emit a Proof Surface packet. Source. Entry: model-provenance-validator envelope.json.
Secret Redact IO Secret Redact IO is a Python library that redacts secrets from file, fetch, write and subprocess output. Source. Entry: secret-redact-io read README.md --json.
Agent Hook Pack Agent Hook Pack installs hooks for secret checks, branch guards, environment synchronization and repository hygiene. Source. Entry: agent-hook-pack audit and agent-hook-pack list.
Repo Proof Index Repo Proof Index scans the proof packets, receipts and contracts in a repository and builds a reviewer index with the type, status, summary and path of each file. Source. Entry: repo-proof-index contracts/*.json --summary.

Complete security and purple-team toolkit hierarchy

All 16 first-class tools across the security and purple-team hierarchy (2.62M+ measured LOC, 2,347 test files, 869 commits), showing maturity, capability role, lineage, and authorization boundary. Live operational payloads, private methods, target details, and raw credentials are never published.

Sovereign · ancestor Early 2026 39-agent security and purple-team routing table. Directly seeded Plexus capability discovery, the Index router, and the Senses routing architecture. Boundary: historical architectural predecessor.
WARDEN / Seed · controlled-private C++23 59-module assessment and detection-engineering runtime (224,887 LOC, 389 test files) with ATT&CK-mapped verification; spun off WARDEN Reporting, WARDEN Sensorium, WARDEN Agent Audit, and WARDEN Release Assurance. Boundary: written authorization and approved environment only.
Sofer · controlled-private 74-package Python domain ledger (1,364,070 LOC, 1,107 test files) covering intelligence, regulatory provenance, vulnerability labs, self-healing verification, and MCP bridging (sensitive hazard domains strictly measurement, evaluation, and safety-layer only). Boundary: authorized engagements only.
ORCA · controlled-private Native assessment runtime (23,011 LOC, 144 commits) enforcing rules-of-engagement admission gates, check-coverage and blind-spot modeling, portable evidence bundles, and linked-hash receipt ledgers. Boundary: written scope required before execution.
Array · controlled-private Authorized wave-planned campaign orchestrator (173,783 LOC, 200 test files, consolidating earlier campaign and run-room platforms, paired with Adversarial at 155,022 LOC) with RoeEnforcer containment and inclusion-proof evidence bundles. Boundary: written authorization and remediation owner required.
Bounds · controlled-private Trust verification across agent, runtime, and release scopes (5,141 LOC, 29 test files), auditing declared intent against actions, runtime sensorium observations, sealed receipts, and attested finding waivers. Boundary: authorized repositories and runtimes only.
Isomorph · controlled-private Inference-boundary refusal measurement and pressure calibration harness (extracted from WARDEN, 172,570 LOC, 243 test files) with hash-chained audit records; its defensive boundary seed fathered EMET and Accountable Surface. Boundary: controlled evaluation scope; live payloads strictly embargoed.
Aleph · controlled-private Private release gate, safety evaluation, and supply-chain intake layer (15,418 LOC, 128 commits) verifying readiness manifests and handoff evidence before advancement. Boundary: approved internal release channels only.
Kun · controlled-private Local access-recovery memory and runbook tracker for owned systems using path-only receipts and redacted diagnostics with zero raw credentials or recovery instructions published. Boundary: owned systems only.
Phantom · shipped Rust Layer 0 to 2 hardware-identity auditor and reversible backup-and-restore utility (v1.1.1, 25,347 LOC, 273 passing tests, 0 production unwraps) for owned or expressly authorized Windows and Linux machines. Boundary: owned or authorized machines only.
EMET · shipped Byte-integrity witness across Python, Rust (with unsafe code forbidden), Node, and Go verifying whether bytes reaching a model or reviewer still match their claimed source, returning MATCH, DRIFT, or UNVERIFIABLE. Boundary: public MIT/Apache inspection tool.
Proof Surface · active Zero-dependency Python library and CLI validating structured AI workflow, authorization, delegation, and witness records into portable evidence packets without executing actions itself. Boundary: advisory verification; human authority remains external.
Crucible · shipped Falsification and claim-verification harness decomposing theses into explicit failure conditions checked offline against execution evidence and canonical engine receipts inside Flywheel. Boundary: public verification harness.
Secret Redact IO · shipped Python redaction wrapper filtering credential-shaped strings from file, HTTP, and subprocess streams while emitting hash-only receipts (consolidated under Flywheel). Boundary: public hygiene utility.
Agent Hook Pack · shipped Public repository hygiene hooks enforcing secret scanning, branch guards, and workspace checks before commits leave the machine (consolidated under Flywheel). Boundary: public workflow guard.
Repo Proof Index · shipped Reviewer-facing indexer cataloging contracts, receipts, and proof packets across repositories while keeping private payloads outside public summaries. Boundary: public or authorized artifacts only.
