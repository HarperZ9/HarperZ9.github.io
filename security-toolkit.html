Security toolkit

Five small public utilities for checking a repository before you publish it, redacting secrets from tool output, validating release source records, installing repository hooks and indexing review packets.

The utilities

Each links to its public repository.

Public Surface Sweeper source. Entry: public-surface-sweeper . --summary. Try it on the sample: public-surface-sweeper examples/clean-repo. It checks release hygiene only; use a vulnerability scanner for dependencies and exploits.
Model Provenance Validator Model Provenance Validator checks JSON records that link a model or release claim to its sources and retrieval dates, redacts credential-like values from its output, and can emit a Proof Surface packet. Source. Entry: model-provenance-validator envelope.json.
Secret Redact IO Secret Redact IO is a Python library that redacts secrets from file, fetch, write and subprocess output. Source. Entry: secret-redact-io read README.md --json.
Agent Hook Pack Agent Hook Pack installs hooks for secret checks, branch guards, environment synchronization and repository hygiene. Source. Entry: agent-hook-pack audit and agent-hook-pack list.
Repo Proof Index Repo Proof Index scans the proof packets, receipts and contracts in a repository and builds a reviewer index with the type, status, summary and path of each file. Source. Entry: repo-proof-index contracts/*.json --summary.
