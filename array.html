Single-technique assessment misses how attacks compose.

Red-team value comes from chaining techniques into campaigns that exercise the same paths an adversary would follow. Array provides the orchestration layer: campaign planning, fixture generation, execution sequencing, and containment enforcement. Seed provides the C++23 runtime that exercises each technique.

The separation is deliberate. Array decides what to assess and in what order. Seed executes each step. The campaign-level receipts compose from the technique-level receipts.

What Array does that Seed does not.

Campaign planning Defines a multi-step assessment as a directed graph of techniques. Each edge carries preconditions and containment requirements. The planner validates the graph before execution begins.
Fixture orchestration Generates and manages the synthetic targets each campaign step needs. Credential stores, registry hives, network endpoints, all created for the campaign and cleaned up after.
Containment enforcement Each campaign step runs inside a containment boundary. The boundary prevents lateral execution beyond the fixture set. Containment violations abort the campaign and record the violation in the receipt.
Campaign receipts Each campaign produces a receipt that composes from Seed's technique-level receipts. The campaign receipt records the full execution graph, timing, containment status, and assessment findings.
